复现命令：

```bash
mvn package
npm run check
npm --prefix prototype run check
npm --prefix qa test
python3 scripts/verify-release.py
REVIEW_TEST_CONTEXT_PATH=/apa REVIEW_TEST_INTEGRATION=1 python3 scripts/verify-release.py
python3 scripts/package-release.py
python3 scripts/verify-startup.py
```

DOM脚本使用qa声明的jsdom依赖；原型检查前按prototype/README恢复固定版本资源。性能测试记录批次、调用次数和实测耗时，不以严格的单次时延作为不稳定断言。DOM不能替代目标浏览器帧率、布局和真实网络时延验收。
