# 设计与验证文档入口

当前生效版本为 **V1.4.0（2026-10-20）**，按尚未上线的前提精简导入与建库。总体架构和一期详细设计仍为原文件，分别描述总体决策与实际实现，不是两套备选方案。

| 文档 | 用途 |
| --- | --- |
| [总体架构设计](总体架构设计_V1.0.md) | 业务边界、两条追溯链、单产品导入、当前架构决策与分期演进 |
| [一期详细设计](一期详细设计_V1.0.md) | 当前字段、校验、关联、接口、性能与部署契约；第17节为本轮详细设计 |
| [原型与交互设计](原型与交互设计_V1.0.md) | 已审核视觉基线及正式运行版的导入、编辑交互；静态原型与运行版边界 |
| [测试用例](测试用例_20261020.md) | 当前产品名称、显式ID、权限、性能、HTTP与空库初始化用例 |
| [验证记录](验证记录_V1.0.md) | 已执行结果与目标环境尚待验收项目 |
| [接口调用说明](数据接口调用说明_V1.md) | 受控JSON/文件上传、查询、修订与发布 |
| [OpenAPI](openapi-integration-v1.yaml) | 机器接口路径及四类字段定义 |
| [V1.4.0发布说明](发布说明_V1.4.0.md) | 当前变化、旧开发库重建、新模板和复现方法 |

四类明细每行均须提供产品名称，并与所选产品一致。POINT/MATRIX_RISK必须提供权限组合ID，USER_RISK必须提供授权记录ID；AUTH无ID逐行保留是独立业务要求。V1.4不做旧文件自动补ID或旧测试库迁移，使用空库和新模板。

历史发布说明[V1.2.1](发布说明_V1.2.1.md)、[V1.3.0](发布说明_V1.3.0.md)仅供变更记录，历史“保留旧库自动升级”操作不适用于V1.4。历史测试记录不替代当前验证。文档路径保留以便既有链接继续打开。
