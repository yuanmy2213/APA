# 设计与验证文档入口

本目录将总体架构、一期实现和交互设计分别管理，三者属于不同层次，并非两套备选架构。

| 文档 | 用途与适用范围 |
| --- | --- |
| [总体架构设计 V1.0](总体架构设计_V1.0.md) | 原已确认架构设计的 Markdown 正文，保持内容不变；说明业务边界、两条追溯链、分期演进及总体技术方案。文中建议项和后续能力不代表已实现。 |
| [一期详细设计 V1.0](一期详细设计_V1.0.md) | 当前运行版本的接口、数据结构、任务、发布、权限和部署约定；一期具体实现以此文和当前源码为准。 |
| [原型与交互设计 V1.0](原型与交互设计_V1.0.md) | 已认可高保真原型的页面、操作路径、状态和设计约束；配套 prototype 目录。 |
| [验证记录 V1.0](验证记录_V1.0.md) | 本轮已经执行的验证及尚未验证的环境条件；不将设计目标视为验证结果。 |

阅读顺序：总体架构 → 一期详细设计 → 原型与交互设计 → 验证记录。

原型用于交互评审，正式 Java + Vue 运行版用于数据持久化和权限控制。二者功能边界及运行方式见原型设计文档。若后续变更影响总体架构，应同步更新架构版本与一期设计，而不是新增一份未标明取代关系的同级方案。
