## 运行与升级

源码仓库先执行mvn package，使用Java 17运行target/finance-access-review-1.2.1.jar，或使用根目录start-demo脚本。体验入口为http://127.0.0.1:8080，prod沿用既有配置。

升级前备份数据库与audit.storage文件目录。替换JAR后保留原data目录和配置。本次没有新增迁移；从V1.1升级仍会执行V1.2已有的V2迁移。不要删除H2文件。

## 复现验证

1. mvn package：后端既有业务与V1→V2迁移回归，同时打包正式前端。
2. npm run check；npm --prefix prototype run check：JavaScript语法。
3. 安装qa依赖、恢复prototype资源后执行npm --prefix qa test：页面/弹窗、处理状态、矩阵名称、环形图排序/分母/零值、导入诊断和版本差异。
4. python3 scripts/verify-release.py：打包后的真实HTTP、静态资源、登录、导入、发布、误报剔除及重启持久化。

实际结果见[验证记录](验证记录_V1.0.md)。DOM检查不替代真实浏览器视觉验收；企业认证、PostgreSQL、生产环境与真实报告关联率继续按既有验收边界执行。
