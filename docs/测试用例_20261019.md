执行命令：

```bash
mvn test

npm run check
cd qa && npm install && npm test
# 在仓库根目录执行
node qa/oct19-ui-test.mjs
node qa/prototype-dom-test.mjs
python scripts/verify-release.py
```

原型测试需先在prototype目录执行npm ci与npm run prepare:assets，恢复固定版本第三方资源。若依赖安装在外部目录，可通过REVIEW_QA_JSDOM指定jsdom模块路径。Java测试的数据库为H2 PostgreSQL兼容模式；企业PostgreSQL、真实统一认证、容量性能与浏览器视觉不视为本轮已验收。
