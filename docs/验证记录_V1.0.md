## 本轮发现并修复

1. Basic认证的密码编码增加BCrypt算法标识，避免默认编码器拒绝校验。
2. 无状态认证下，后续认证GET会触发默认CSRF认证策略清除Cookie；配置无会话认证策略后保持CSRF校验，并通过真实HTTP流程和回归验证。
3. 原始用户稳定键、业务元组键与证据修改历史补齐；跨产品统计及跨版本回看保持一致。
4. 全域和产品导出包含两条风险链路，并绑定快照与幂等键。
